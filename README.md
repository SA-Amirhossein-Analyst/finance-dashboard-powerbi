# Finance Dashboard – Power BI

A portfolio Power BI project focused on financial performance, profitability, and budget analysis.

## Dashboard Scope

The dashboard includes four main analysis areas:

- Executive Overview
- Budget Analysis
- Profit Drivers
- Insights & Analysis

### Key Analysis

- Sales and profit performance
- Profit margin and COGS
- Actual vs. Budget comparison
- Budget variance analysis
- Profit by country
- Profit by segment
- Profit by product
- Profit trend over time
- Decomposition Tree for profit analysis
- Interactive slicers and filtering

## Data Source

The project is based on the **Microsoft Power BI Financial Sample** dataset.

Official source:  
https://learn.microsoft.com/en-us/power-bi/create-reports/sample-financial-download

The dataset contains sample financial data covering sales, profit, products, countries, segments, and time periods.

## Budget Data

The Budget Analysis section uses synthetic budget figures created for educational purposes.

The budget data does not represent real company financial information.
